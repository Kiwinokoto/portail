# French vocabulary audio sources

Portail prefers human recordings for isolated French vocabulary before falling back to browser speech synthesis.

- Main speaker: **Sartus85**, recordings produced with Lingua Libre and hosted on Wikimedia Commons.
- Main licence: **CC BY-SA 4.0**. Portail does not modify the recordings.
- Current fallback for `brosse à dents`: **Pamputt**, Lingua Libre, **CC0**.
- Current fallback for `toilettes`: **Justforoc**, Lingua Libre, **CC BY-SA 4.0**.
- Runtime URLs use Wikimedia Commons `Special:Redirect/file/` with the original file names.
- Browser speech synthesis remains a fallback only for dynamic text or phrases for which no curated human recording exists.

The temporary admin comparison UI used to choose this direction was removed after field testing on 2 October 2026.
